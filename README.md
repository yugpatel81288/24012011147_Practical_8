# Hello World iOS App – SwiftUI

## 📌 About the Project
This project demonstrates how to create a basic **Hello World iOS application** using Swift and SwiftUI in Xcode.

It is developed as part of the Mobile Application Development practical for learning the fundamentals of iOS app development.

## 🎯 Aim
To create your first Hello World iOS application using SwiftUI.

## 🛠️ Technologies Used
- Swift
- SwiftUI
- Xcode
- iOS Simulator

## ✨ Features
- Displays a simple "Hello, world!" message.
- Uses SwiftUI to build the user interface.
- Demonstrates the basic structure of an iOS application.
- Supports running the application in the iOS Simulator.
- Allows previewing UI changes directly in Xcode.
